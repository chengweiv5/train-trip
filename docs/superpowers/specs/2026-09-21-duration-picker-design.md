# 最长车程预设和时长选择器

用户要求将最长车程的预定义时长改为3小时、5小时，自定义改用时间选择器。按已确认B4风格和现有出发时段滚轮交互实现，不再输入分钟数。

## 交互与边界

在最长车程底部面板中提供“不限、3小时、5小时、自定义”四个选项，普通字号单行等宽，窄屏或较大字号时两列，点击范围至少48dp。不限/3小时/5小时分别为null/180/300分钟。自定义选中后在同一面板展开小时、分钟两列滚轮，展示“最多 X 小时 Y 分钟”的实时摘要，完成保存、取消或系统返回不写入。隐藏滚轮时保留本次自定义草稿，重新选择自定义可继续调整。

打开时按原值回显：null选不限，180/300选对应预设，其它值选自定义；原来4小时/8小时自动作为自定义保留，不改现有持久化格式。不限下首次选自定义以3小时为初值。保留原1–6000分钟范围：小时0–100，分钟0–59，100小时分钟固定00；总时长0禁用完成并提示至少1分钟。滚动未停止时禁用完成，避免保存过渡值。超过24小时显示时长，不套用一天内时刻规则。

## 实现

新增DurationFilterSheet，FilterSheet的duration分支分派到它，移除旧文本框及解析。复用TimeFilterSheet的原生NumberPicker滚轮为internal TimeWheel，抽到TimeWheel.kt；保留原出发时段行为并支持动态max和可选wrap。最长车程仅写SearchFilters.maxMinutes，其它筛选条件和单城查询隔离保持不变。用rememberSaveable保存选项及滚轮草稿；使用当前ModalBottomSheet、B4颜色和可滚动正文/固定底部操作。
