# 出发时段多选验收

日期：2026-09-21。分支：`codex/v0.6.0-b4-ui`。版本保持`0.6.0` / versionCode `10`。修改前提交：`2e2fae1`。

## 实现

- 凌晨、早上、下午、晚上可独立多选；早上＋晚上仅匹配 `[06:00,12:00)` 与 `[18:00,24:00)`，不包含中间空档，不增加查询请求或重复车次。
- 点击全天、取消最后一项或四项全选恢复全天。首页显示实际区间，结果摘要按时间顺序显示中文时段名；快捷按钮带勾选语义。
- 自定义仍为一个连续起止区间，保留跨午夜规则。从多选进入时以最早已选段作为初值；完成替换、取消保留。
- 本机保存稳定时段枚举名，保留旧 `from/to` 字段。无新字段或新字段异常时沿用旧区间及其它有效条件。首页与单城查询的草稿隔离保持原有行为。
- 未增加依赖，未修改票源、服务密钥、收藏和版本号。
