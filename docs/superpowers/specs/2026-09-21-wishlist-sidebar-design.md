# 想去省份双栏（已确认）

用户确认同一方案的河北、山东两个状态符合预期。Pencil 源为 `design/train-trip-surface-contrast.pen`，说明 `D27TnA`，页面 `fLUsq`、`T33a9`。

## 展示与交互

- 复用目的地选择器的省份行：94dp 左栏、至少 52dp 点击高度、浅蓝背景和选中高亮；仅列有收藏的省份及数量。省份顺序沿用行政目录。
- 右侧仅展示当前省份收藏，按已有 `addedAt` 降序，时间相同保持原顺序。标题显示省份、数量和“最近收藏优先”。
- 紧凑卡片显示城市名、收藏日期、星标、介绍状态，以及“了解目的地”“查车票”。收藏日期使用北京时间 MM-dd；往年日期带年份。点击卡片进入介绍，操作点击区域至少 48dp。无可查询站的城市保留介绍和收藏，禁用查票。
- 保留顶部添加城市和底部查票/想去导航。宽度小于 360dp 或字体缩放大于 1.15 时，复用目的地选择器的省份下拉形式，城市列表占满宽度。
- 每省城市列表独立保存滚动位置，省份栏也保留位置；离页返回及 Activity 状态恢复保留当前省份和浏览位置。临时重新加载不重置状态。
- 当前省最后一座城市被取消后选同位置的下一省，无下一省则选上一省；全部清空沿用现有空状态。撤销恢复原收藏时间与省内顺序，不强制跳离用户正在浏览的省份。
- 读取失败明确显示重试，不冒充空列表；保存失败保持现有列表。目录未知城市按现有存储省份归组，仍显示名称，查票禁用，不修改或丢失记录。

## 边界

本次只修改想去浏览 UI 和状态，复用现有收藏分组与持久化，不迁移数据、不改变查询目的地选择或调用内容服务。保留版本 0.6.1 / 11；公开发布和真机安装按用户后续指令处理。

## 验证

离线验证跨省切换、降序、移除最后城市与撤销、空/错误/加载状态、独立滚动恢复、页面离开返回、Activity 状态恢复、无站/未知城市，以及 320dp/1.3 字体。目的地选择器复用行相关测试回归。正常宽度运行截图与 Pencil 比对，核心测试、构建及 Release lint 通过后本地提交。
