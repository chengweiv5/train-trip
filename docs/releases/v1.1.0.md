# v1.1.0 · 先选城市，查票时再提醒

调整出发地与目的地相同时的校验时机，让更换路线更顺畅。

## 本次修复

- **选城市不中断**：选择出发城市或目的地时允许暂时同城，不再提前要求重新选择，也不会自动移除同名目的地。
- **查票时再校验**：点击查票后，若没有目的地或只有出发城市，才提示调整；无效条件不发起查询。
- **多目的地继续可用**：包含出发城市时保留已选范围，仅查询其他城市；结果页不再把跳过的同城显示为“查询尚未开始”。
- **保留已保存条件**：重启仍保留选择；取消编辑不改变原条件。单城市查票入口与首页条件继续隔离。

## 相比 v1.0.0 的其他变化

- 统一查票和候补的席别选择，支持全选、全不选；两个入口独立保存条件。
- 调整候补主页和结果页导航，明确返回层级，支持重新查看上次结果。
- 包含候补试验流程：车次与需求选择、账号密码及短信登录、乘车人选择、官方验证、确认提交和订单回查。

**候补功能仍处于试验阶段。** 真实风控、真实订单提交与回查、生产自动排除流程尚未完成全链路验证；不承诺自动候补或抢票成功。建议在铁路 12306 App 中完成正式购票，以官方实时信息和订单状态为准。版本发布不代表候补全链路已验收。

## 下载与升级

- 安装附件：`train-trip-v1.1.0-release.apk`；另附同名 `.sha256` 校验文件。
- 包名：`cn.traintrip.app`；版本：`1.1.0` / versionCode `16`；Android 8.0 及以上。
- 沿用既有生产证书，可覆盖同签名正式版。签名冲突时保留原安装与数据，不要卸载。
- “有票再出发·开发”（`cn.traintrip.app.dev`）是独立应用，本正式包不会覆盖开发版；开发版数据也不会自动迁移。
- 安装包不含个人内容服务 Key；查票、收藏和主题切换无需配置内容服务。升级不会自动重新生成城市介绍。

本次城市交互已由用户在开发版验收；发布版本通过 206 项核心测试、22 项 Android 单元测试及 35 项相关 UI 回归，正式包通过生产签名和 v1.0.0 覆盖升级验证。详情与公开附件校验见[发布验证记录](https://github.com/chengweiv5/train-trip/blob/main/docs/verification/2026-10-08-v1.1.0-release.md)。
