# v0.7.0 · 想去城市，一目了然

先看哪里有票，再决定去哪里。这次让想去清单更好找，也补齐了旅行介绍和更新记录。

## 更新内容

- **想去按省份浏览**：左侧选省份，右侧查看城市，省内最近收藏排在前面。
- **新增「全部」入口**：固定在省份上方，汇总所有收藏，跨省按最近收藏排序，并显示城市所属省份。
- **记住浏览位置**：全部与每个省份分别保留滚动位置；返回页面或恢复界面时延续选择。窄屏、大字体下提供下拉选择。
- **目的地多图相册**：最多 5 张图片，支持横滑、查看大图与来源；兼容已有单图介绍，手动更新后才获取新内容。
- **保留更新检查记录**：设置页可查看上次检查时间和结果，返回或重启后仍保留。
- **名称与界面统一**：应用名称改为「有票再出发」，子页面沿用冰蓝湖蓝顶部与圆角返回入口。

## 下载与升级

下载附件 `train-trip-v0.7.0-release.apk`，支持 Android 8.0 及以上。版本号为 `0.7.0`，versionCode 为 `12`，使用与 v0.4.0 / v0.5.0 / v0.6.0 相同的正式签名，可直接覆盖升级并保留本机数据。另附 `.sha256` 文件用于完整性校验。

APK 不包含个人 DeepSeek 或 Tavily Key。查票、想去清单和内置城市介绍无需 Key；为新城市整理介绍时再到设置中填写自己的配置，只有手动整理或更新才调用服务。

历史设备专用测试包与公开正式包的签名不同，不能交叉覆盖；遇到签名冲突请先确认安装来源，避免卸载丢失收藏和设置。

应用用于发现目的地和查询直达去程余票，不提供抢票或代购。余票以 12306 实时查询及下单结果为准。
