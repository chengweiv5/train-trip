# 最长车程选择器验收

日期：2026-09-21。分支：codex/v0.6.0-b4-ui。修改前提交：20ee691。版本仍0.6.0/10。

## 改动

- 预设改为不限、3小时、5小时；自定义选项在同一底部面板展开小时、分钟滚轮，显示当前最长车程。取消/返回保留原值，完成后保存。
- 自定义范围仍为1–6000分钟，小时支持0–100。0分钟禁用完成，100小时分钟固定00；不将车程限制为一天内时刻。滚动中禁用完成，切换预设或移除滚轮清理滚动状态。
- 旧240/480分钟值以自定义回显，沿用SearchFilters.maxMinutes和Preferences格式；只修改最长车程，其余条件不变。未增加依赖或修改票源、密钥、收藏。
- DurationFilterSheet独立处理草稿和面板，TimeWheel从原出发时段文件抽出共用。保留原时段滚轮行为，补充动态max与可选循环。
