# 目的地行政目录

本版使用稳定行政代码，目录与铁路查询能力分开保存。城市名省略普通“市”后缀；自治州、地区、盟、自治县保留全称。直辖市只保留一个目的地。

- 行政目录基线：[Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China/tree/c49d495b40ac73eb1a66f6eeae5f8fd10696f035)，其 README 标明来源为国家统计局 2023-06-30 统计用区划快照，并说明已停止更新。不是 2026 年实时目录。
- 本地原始快照：`scripts/data/administrative-divisions-2023.json`（省/地/县三级），许可：`scripts/data/administrative-divisions-LICENSE`（WTFPL）。港澳台参考同版本 `dist/HK-MO-TW.json`；香港/澳门各一项，台湾保留 22 个市县且禁用 12306 查询。台湾本地 ID 为本应用稳定命名空间，不声称是官方行政代码。
- 应用目录：`core/src/main/resources/destinations.json`，34 个省级地区、391 个目的地。省直辖的实际县级行政单位直接呈现；普通地级市的县、县级市及区均归到地级单位。
- 映射：`station-city-mapping.json` 固定保存 424 个旧铁路城市 ID、旧名称、目标代码，运行时同时匹配 ID 与名称，避免铁路字典复用 ID 时静默误归属。未知新组标记为 unmapped，仍留在 byCode 供协议检查，但不创建未经证实的城市。
- 5 个站级修正：阿拉尔 AOR、图木舒克 TMR、北屯市 BXR、双河市 OHR、昆玉 ESR 从铁路大组中分出，归入对应省直辖市。名称和省直辖身份由行政目录交叉确认。
- 自治州别名（如西昌、吉首、库尔勒、凯里）通过行政子项反向归并；北京、重庆、海南昌江等歧义短名显式复核；省/市排序使用存储的无声调拼音，重庆、长春、长沙、长治、六安、厦门、蚌埠、成都、佛山等多音字经修正。

## 更新与能力边界

修改目录时需保留稳定 ID，新增别名而非覆盖旧 ID；一并维护来源、站级例外和目录测试。行政快照可能滞后，不能宣称已实时核验全国全部车站归属。铁路字典仍可能收录未运营站，不能把“存在站”当成“有班次”。

旧选择迁移会将拆分后的多个行政目的地全部保留；指定出发站时采用该站唯一对应的行政城市。每个合并前的铁路城市保留一个代表站参与查询，避免合并后丢失原有线路覆盖；并不承诺覆盖该行政城市每一站。查询时间可能随合并后的代表站数量增加，原有停止/继续功能保留。
