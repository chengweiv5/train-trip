# 民间攻略检索与邯郸重验

## 已确认问题

旧版仅在政府、官媒、携程、马蜂窝范围内检索，没有独立路线查询。真实豆包结果中“邯郸娲皇宫”因为不含完整“娲皇宫景区”被丢弃，邯郸道新浪游记图因来源白名单被拒绝。限流通过 HTTP 200 的业务 700429 返回，不能把 HTTP 成功等同于检索成功。

## 改动

- 首轮按景点游记、美食体验、一日游、两天一夜四类检索携程、马蜂窝、穷游、什么值得买、新浪、小红书。图文不足时有界补查，政府官媒不进入主要攻略语料，公开民间来源可收录。
- 单篇网站限量，来源去重；同一游记可提供景点、美食和路线，检索标签不再阻止有效内容提取。
- 图片原名查询，无候选时增加简称/实景或菜品关键词查询；稳定通用尾缀可省略，步行街不当成公园。美食图片按具体菜名识别并标注菜品参考图。
- 路线保存每天的原始引用与 URL，校验景点出现及先后顺序；只有明确日程箭头结构才启用自动提取后备。已有 UI 增加查看攻略原文。
- 串行间隔与限流有限重试；景点、美食各十项，每项三图规则不变。

## 验证证据

- 新增民间来源和景区简称回归在旧实现均失败。
- 132 项 core 测试通过，Debug/Release 编译和 lint 通过。
- 邯郸同一真实模型输出经新版解码得到4个景点、3种美食、1日/2日两条攻略；所有景点与美食引用都在对应 Content 原文中，路线保留同源原文。
- 使用生产图片源逐项搜索并下载解码12张，覆盖4/4景点和2/3美食。南沿村拉面未取得合格图片；郭八火烧和驴肉火烧有菜品图。全部下载图已目检。
- 搜索结果有动态变化；这是该次样本结果，不能声称所有城市均有图或保证十项凑满。民间网站也可能转载或标注AI整理，来源链接可供用户判断，不声称都是一手亲测。

用户明确要求清除全部城市缓存。通过应用原生删除入口删除邯郸、保定、蚌埠、承德、廊坊、泰安；清理后已下载0城市、0.0KB。重新启动并安装搜索改进版后回读仍为0城市，DeepSeek与豆包显示已配置，5个想去城市保留。

已安装匹配手机既有证书的Release构建（不可调试，界面版本仍0.8.0/code13），开始仅对邯郸全新生成，首次回读显示7个景点和回车巷2图。用户随后切换到另一应用，停止操作等待最终回读；不能把电脑样本数字当作手机最终结果。其他城市没有重新生成。

脱敏完整原文、模型输出、下载图、构建日志、缓存清理证据位于 `.verification-private/community-search/`（不入库）。修改前源码归档 `before.tar`，手机旧APK在 `.verification-private/doubao-phone-install/installed.apk`，可使用同证书覆盖回滚，不卸载。
