# v1.0 主题切换 Implementation Plan

> 执行方式：当前任务内按步骤实现、验证、复核。writing-plans 引用的 executing-plans/subagent-driven-development 技能未安装，使用本计划内联执行。

**Goal:** 按已确认的四套浅色设计，实现全局即时切换、本机持久化和失败恢复。

**Architecture:** 主题标识及存储、主题 ViewModel、不可变色板、设置主题页分别负责一项工作。根节点提供 CompositionLocal，保留现有颜色属性名和页面状态；所有动态颜色在组合时读取，原生 NumberPicker 在 update 中应用已捕获颜色。

**Tech Stack:** Kotlin、Jetpack Compose Material 3、ViewModel/StateFlow、Android AtomicFile、JUnit、Compose instrumentation。

## Global Constraints

- 四套浅色：晴空蓝、松林绿、暖阳橙、暮山紫；默认 BLUE，稳定存储 ID 为 blue/green/orange/purple。
- 保留查票、收藏、配置、缓存与滚动状态；不触发搜索、模型或网络请求。
- 白底固定，语义绿统一 #0F7952，提醒 #A8500C；全部动态角色采用已确认规格。
- 宽度 <360dp 或 fontScale>1.15 单列，最低命中 48dp，主题页可滚动。
- 开发在 codex/v1.0-theme-design；不推送、不发布、不操作个人手机。保持当前版本标识，功能作为 v1.0 候选。

### Task 1: 主题选择与持久化

Files: `app/src/main/kotlin/cn/traintrip/app/ThemePreference.kt`、`ThemeViewModel.kt`、`app/src/test/kotlin/cn/traintrip/app/ThemeViewModelTest.kt`、`app/build.gradle.kts`。

接口：`enum class ThemeChoice(val id:String,val label:String)`；`interface ThemePreference { fun read():ThemeChoice; fun save(choice:ThemeChoice) }`；`ThemeUiState(choice,loading,saving,message,error,event)`；`ThemeViewModel(preference,ioDispatcher)` 提供 `state`、`select(choice)`、`reload()`、`clearFeedback(event)`。

- [x] 为未知 ID 默认、加载失败重试、保存失败回退、重复选择无写入、快速点选不被旧结果覆盖编写测试；使用 StandardTestDispatcher 控制阻塞读写。
- [x] 用私有 `AtomicFile(filesDir/theme-choice)` 保存稳定 ID：`startWrite → write UTF-8 → finishWrite`；异常 `failWrite` 后抛出，避免失败污染既有配置。读取不存在/未知 ID 返回 BLUE；实际 I/O 异常由状态机处理。
- [x] ViewModel 启动在 IO 读取；未完成加载禁用选择。选择先更新预览，用 Mutex 顺序提交；跳过未开始的过时请求，已成功提交更新 confirmed；只让最新请求更新可见反馈。失败回退 confirmed。
- [x] 运行 `:app:testDebugUnitTest`，验证上述失败和竞态。

核心状态转换：
```kotlin
val request = ++generation
state.value = state.value.copy(choice = choice, saving = true, message = null, error = null)
viewModelScope.launch {
    writes.withLock {
        if (request != generation) return@withLock
        try {
            withContext(ioDispatcher) { preference.save(choice) }
            confirmed = choice
            if (request == generation) state.value = state.value.copy(saving = false, message = "已切换为${choice.label}")
        } catch (e: Exception) {
            if (e is CancellationException) throw e
            if (request == generation) state.value = state.value.copy(choice = confirmed, saving = false, error = "未能保存主题，请重试")
        }
    }
}
```
