# v0.4.0 车次信息页 UI 设计

状态：UI 已确认并落盘；用户随后授权修改实现，v0.4.0 Android 功能和 APK 已完成。运行证据见 [实现验收](../../verification/2026-09-19-v0.4.0-implementation.md)。本文件的设计验收与实现验收分开记录。

## 范围与目标

沿用深绿、暖白视觉和现有日期、到达站筛选、排序、车次信息结构。优化从选择车次到打开铁路12306 App 的路径：点选席别 → 核对已选摘要 → 打开 12306 App。跳转目标按用户最新要求固定为 App。

主按钮不再承担强制核验；刷新余票成为列表上方的主动操作。按用户最终确认移除复制车次功能，底部仅保留已选摘要与主操作。主按钮不等待网络核验、不弹二次确认。

可编辑源文件：[train-trip-v0.4.0.pen](../../../design/train-trip-v0.4.0.pen)。日期、车次、余票与查询时间均为设计示例。

## 页面与组件

| 画板 | 节点 | 作用 |
| --- | --- | --- |
| 设计说明 | `bi8Au` | 版本范围、目标、示例声明 |
| 未选择 | `xUauz` | 点选席别提示、未选择摘要、禁用主按钮 |

两个可复用组件：主按钮 `WNMsd`、席别选项 `DAfHT`。文本、图标、布局、颜色变量和组件实例均保留可编辑结构。

## 席别选择

- 列表上方显示“点选席别，底部查看已选车次”。
- 点击具体席别才建立选择，车次卡片空白区域不隐式替用户选择席别。
- 一次只选择一个“日期 + 车次内部编号 + 出发站 + 到达站 + 席别”的组合。
- 选中车次用浅绿底、深绿描边和“已选择”文字标明；选中席别用深绿底、白字和勾选图标标明。避免仅靠颜色传递选中状态。
- 日期在每张卡片中独立展示，时刻、到达站、跨日到达、各席别余票含义保持原规则。
- 切换日期或到达站后，如果选中项不再属于可见结果，清除选择并回到未选择状态。切换排序保留选择。
- “更多席别与余票”仍是查看全部状态的入口，不因展开而改变选择。

## 底部操作区

标准宽度 412dp，水平内边距 20dp；白色背景、顶部细分隔线，独立于滚动车次列表。列表底部留出操作区与系统安全区的实际高度，不遮住最后一张卡片。

未选择时显示“先点选一个席别”，下一行说明“选好后，可打开 12306 App”；主按钮显示“打开 12306 App”但禁用。

已选择时，摘要第一行显示“C2031 · 9月25日 · 二等座”，第二行显示“北京南 08:00 → 天津 · 1位成人”。摘要占满内容宽度，允许自然换行，不截断长站名、日期或人数。

唯一高强调主按钮为“打开 12306 App”，使用手机图标。下方常驻“在 12306 App 内填写条件并购票”。点击直接唤起设备上已安装的铁路12306 App。

本版本设计要求唤起 App，不自动打开官网作为降级。自动填入条件、选定车次或直接购买不在当前设计承诺范围内。回到本 App 时保留筛选、选择和滚动位置。

## 刷新与跳转反馈

“刷新余票”位于列表上方，与最近成功查询时间并列。刷新范围为当前城市、已应用出行条件对应的查询项；日期与到达站仍为本页筛选。刷新期间保留旧结果和选择，按钮显示“正在刷新余票…”并阻止重复点击；可继续浏览或打开 12306 App。

刷新成功后保留仍符合席别和人数的选择；如果已选车次消失或不再满足条件，清除选择并提示“所选席别当前不满足人数，请重新选择一个席别”。余票含义沿用现行规则，不在此版本调整“有”、具体数字、候补或未开售的匹配含义。

刷新失败显示“余票未更新”“上次成功更新 09:41”和“重试刷新”，保留旧结果及其原始时间。部分失败应按查询项保留旧结果、标明未更新范围，不把失败项当作无票，也不把全部结果标成刚更新。

未安装时显示“未安装铁路12306”“安装后重试，已选车次会保留”。已安装但唤起失败时显示“暂时无法打开 12306 App”“已选车次会保留，请稍后重试”。两种情况下均保留列表和选择，允许重试，不自动打开浏览器，不自动安装应用。

## 字体、窄屏与可访问性

- 主按钮高度 56dp，其他操作点击区域至少 48dp；图标不是唯一的操作说明。
- 320dp 或大字体下筛选与席别纵向排列；发到时刻保持双列，耗时与跨日说明下移。
- 摘要使用全宽容器，文字自然换行；底部随文字自然增高，主按钮在所示 1.3 倍字体下为 60dp。
- 实现使用系统实际 Insets，不固定写入设计稿中的状态栏 62dp 和底部 28dp。
- 向辅助服务提供席别选中状态、禁用状态和刷新状态；反馈由辅助服务播报，不能仅依赖颜色或短暂动画。
- 设计画板展示全部内容，超过屏幕高度是长页展开展示；手机上使用滚动容器，不能把长画板整体缩小塞入一屏。

## 验收边界

本次验证对象为设计稿：可编辑层级、变量、组件实例、文本、容器边界、同级重叠、点击尺寸、颜色对比度、OCR 与最终渲染。

Android 实现时另需验证：选择及清除、筛选隐藏选择、刷新中与部分失败、已选车次失效、复制入口不存在、铁路12306 已安装时成功唤起、未安装提示、唤起失败提示、返回保留位置、实际安全区和大字体滚动。目标设备已验证通过 PackageManager 解析 com.MobileTicket 的启动入口；不使用私有深链或参数预填。本次设计验证不能替代运行验证，最新运行证据见 [移除复制入口验收](../../verification/2026-09-19-v0.4.0-remove-copy.md)。
