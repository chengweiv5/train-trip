# UI Polish Implementation Plan

**Goal:** 修复同窗日期范围、连续进度条和车次中间信息，并同步 Pencil。

**Architecture:** 现有 Compose 页面调用独立日期弹层和小型展示组件，业务查询层不变。日期组件以 UTC 毫秒与 LocalDate 转换；最终筛选沿用 SearchFilters.validate。

**Tech Stack:** Kotlin、Compose Material 3、Pencil MCP、Android 仪器测试。

## Global Constraints

- 分支 `codex/ui-polish`；修改前备份；所有 UI 变更同步现有 `.pen`。
- 保持原主题，最多查询 31 天，不把未知到达日显示为当日。
- 不修改真机偏好或运行会清空其数据的测试。
