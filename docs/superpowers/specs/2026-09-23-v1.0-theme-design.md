# v1.0 主题配色设计稿

状态：用户于 2026-09-23 确认完整设计稿，Android 实现与本地验证已完成。发布与推送另行授权。

## 目标与基线

用户要求“v1.0 支持多个主题配色，并且支持切换，先出设计稿”。已确认晴空蓝、松林绿、暖阳橙、暮山紫四套浅色。基线为 `ef0b1e6` 的 `Theme.kt`、首页与设置源码，以及 README 的 v0.9.0 实际界面截图。查询界面保持白底、浅色卡片、现有标题层级、圆角和信息密度。晴空蓝采用现有主色 `#0073AA`，升级后外观延续当前版本。

选择预设整套配色：用户能直接判断效果，文字与状态色便于统一验证。只切主色会留下不协调的卡片、边框与页头；自由调色和系统动态色增加组合与辨识成本，本稿不采用。深色模式不在本次已确认范围内。

## 页面与切换

设置页顶部新增“外观”分组，单行入口“主题配色”，右侧显示当前色点、主题名称和进入箭头；下方保留内容服务、本机内容和关于与更新。

主题页展示当前效果预览和 2×2 选项。每项包括名称、主色/浅色/白底预览、单选图标与状态文案；当前项显示边框、勾选及“使用中”。晴空蓝未选中时标注“默认配色”。选项整块可点，最低点击区域 48dp，辅助文字不低于 12sp。效果预览使用设计示例数据，预览中的查询按钮只是展示外观，不触发查询。

点击目标主题后即刻预览本页及全局配色，保持在当前页面；保存成功后显示“已切换为松林绿”类短反馈，无额外确认按钮。返回设置显示新的名称与色点，回到业务页保留原状态。点击当前主题不重复写入。选择保存在本机，下次启动沿用；离线也可切换。连续点击以最后一个成功提交的选择为准，异步旧结果不能覆盖新选择。

首次使用、从没有主题偏好的旧版首次升级默认晴空蓝；已有有效偏好的后续升级继续沿用所选主题。配置缺失或无法识别时回退晴空蓝。启动读取失败时可临时显示默认主题，保留原配置以便重试。保存失败恢复先前成功主题和单选态，显示“未能保存主题，请重试”；再次点目标项重试。画板 12 示例为松林绿切换其他主题失败，仍保留松林绿。

白色页面/控件底和主按钮白字固定。HeaderControl 固定为 80% 白色（Compose `#CCFFFFFF`，Pencil `#FFFFFFCC`）；Subtle 映射辅助文字，HeaderTop 映射选中浅色。主题覆盖品牌页头、按钮、导航选中态、日期/时段/省份选择、卡片、边框、链接、收藏及车次标记；照片与原始旅游资料不染色。Pencil 变量 `v10-*` 使用“配色”主题轴表达四套角色，可在编辑器直接切换画板主题。

有票/成功保留绿色语义与 `#EAF7F0` 浅底。对比度检查发现原绿 `#12845B` 在浅绿底上只有 4.26:1，因此四主题统一微调为 `#0F7952`，保证小字可读；提醒/失败继续使用现有 `#A8500C` 与 `#FFF4E5`。不随主题更改语义。暖阳橙接近提醒色时，按钮、提醒容器、图标与文案共同区分用途；车票有无、当前主题和收藏选择均不得仅依靠颜色表达。

## 适配与状态边界

主题页宽度低于 360dp 或字体缩放大于 1.15 时使用单列选项，文字与选项高度随内容增长，页面整体可滚动。320dp 画板为大字号内容展开示意，保留全部选项和系统安全区；不代表所有字号都由固定画板高度容纳。首页画板采用 390dp 宽和 920dp 展开高度，短屏按既有页面滚动。

主题切换保持日期、人数、筛选、当前业务页面、车次标记、想去省份和滚动位置；不重新查票，不重新生成目的地内容，不修改收藏/离线缓存/凭据。应用导航与照片查看仍按原有交互。全部业务页、设置子页、弹层、加载/错误/空状态均使用同一主题来源，避免局部保留旧色。

实现分为独立配色定义、本机主题偏好、应用级主题宿主、主题选择页四个边界。定义只提供颜色角色；偏好只负责选择持久化；宿主向整个 UI 提供当前主题；选择页只管理展示与点选。Android 单选图标沿用 Material 3 原生圆点样式，并同时显示边框和“使用中”。
