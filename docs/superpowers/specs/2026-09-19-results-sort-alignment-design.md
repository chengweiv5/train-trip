# 结果页排序入口左对齐

用户指定：结果页城市排序文字居左，刷新继续位于右侧，形成两端布局。沿用已确认的目的地更新入口左对齐原则。

当前排序 TextButton 使用 weight(1f) 占据剩余宽度，其内部文字默认居中。保留按钮的宽度分配、零内边距和点击区域，仅让 Text 填满按钮内容宽度并按 Start 对齐。两种排序文案「省内 · 车程最短 ↓」「省内 · 车次数最多 ↓」均应用；刷新按钮及禁用条件、排序回调和分组逻辑保持不变。窄屏时文字可自然换行。

验收：构建与 lint；实际 UI 核对两种排序文案贴齐页面左边线，刷新仍在右侧，点击排序仍切换文案，按钮至少 48dp 点击高度。顺带完成上一项目的地更新入口的待验布局测量。优先在已授权且可用的真机进行；若手机正在使用其他应用，在独立模拟器完成布局验证，不中断用户。

版本保持 0.4.0 / 8，个人版本仅在功能分支本地提交。源码及旧 APK 已备份到 `.verification-private/v0.4.0/results-sort-alignment/`；保留数据覆盖安装，回滚可用 before.apk 覆盖安装。本次无内容生成或密钥修改。
