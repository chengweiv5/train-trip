# v1.0.0 Release Plan

执行方式：当前任务内依次执行。writing-plans 引用的执行子技能未安装，按已有发布流程内联执行。

**Goal:** 发布包含四主题与独立玩法规则的 v1.0.0 正式 APK，核验升级与公开附件。

**Architecture:** 业务代码沿用已推送 `600c376`，只更新版本和发布材料。生产证书在仓库外，通过文件参数读取密码；公开包和设备历史证书包分开。

**Tech Stack:** Gradle、Android SDK 36、apksigner、GitHub CLI、专用 Android 模拟器。

## Constraints

- 功能分支 `codex/release-v1.0.0`，versionName `1.0.0`、versionCode `15`。
- 使用正式生产证书；APK 不纳入 Git，SHA256 纳入。不得卸载个人手机应用或清除个人数据。
- 原始证据与修改前备份保存在 `.verification-private/v1.0.0/`。
- 用户已授权发布；快进推送使用 `git push origin HEAD:main`，不改写既有标签。

## Steps

- [x] 刷新 origin/main、开放 PR 和正式版本；无开放 PR，当前最新 v0.9.0，无 v1.0.0。
- [x] 更新 `app/build.gradle.kts` 到 1.0.0 / 15；更新 README、开发历史、新增 `docs/releases/v1.0.0.md`。
- [x] 运行 `:core:test :app:testDebugUnitTest :app:assembleRelease :app:lintRelease --offline --console=plain`，签署生产包，核对证书、版本、内容和校验值。
- [x] 下载并验证上一正式 APK，专用模拟器建立筛选、收藏、离线图文与配置样例；覆盖升级并逐项回读。验证默认蓝和切换后的冷启动恢复。
- [ ] 补齐 `docs/verification/2026-09-23-v1.0.0-release.md` 和 APK SHA256；检查链接、差异、版本，提交并快进推送。
- [ ] 创建 v1.0.0 草稿并上传 APK/SHA256；回读后公开为 Latest，重新下载逐字节比对签名与版本，回读标签和正文。
- [ ] 将发布结果写回验收、任务状态并提交推送文档；关闭专用模拟器；punk-12 通知并回读。

回滚：发布前可恢复备份。公开后不移动标签；通过同证书、更高 versionCode 的修复版回滚业务。旧 v0.9.0 不支持全部新路线字段，不直接降级或宣称旧包可完整读取新缓存。
