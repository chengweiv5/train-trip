# 想去全部入口

用户要求在已确认并安装的想去双栏省份上方增加“全部”，列出所有收藏城市。沿用现有布局，无新视觉方向。

- 左栏顶部固定“全部”及收藏总数，下面保留有收藏的省份；窄屏/大字体下拉第一项也为“全部”。
- 初次进入默认全部，已有省份浏览状态保留。全部平铺所有收藏，按 addedAt 从新到旧排序，不按省再分段。
- 全部是浏览范围，不是行政省份，概况仍只统计真实省份数。全部的城市卡补充省份，便于区分归属；省份视图维持已确认的卡片。
- 全部与每个省份保存独立滚动位置；离页返回及状态恢复不变。取消、撤销、空/加载/失败、未知城市与查票入口沿用现有行为。最后一个省份被清空且清单仍有城市时保留相邻省份回退。
- 只调整展示，不改收藏存储、版本和查询目的地选择器。同步 Pencil；相关离线回归、构建与截图核验后本地提交，不自动推送或安装。
