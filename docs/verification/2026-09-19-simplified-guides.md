# 目的地简体资源验收

日期：2026-09-19；版本 0.4.0 / 8。

## 问题与修复

保定旧缓存引用了人民网 `http://he.people.com.cn/BIG5/n2/2021/1003/c192235-34942447.html`。野三坡正文、地址和来源标题保留繁体原文。搜索 `language=zh-cn` 无法保证返回简体结果，原实现仅检查国内域名，缺少字形/版本校验。

- 搜索排除繁体版 URL（含编码及锚点）、繁体标题和完整返回正文；不先截断再检测。图片说明或图片 URL 不合格则弃用该图片。
- 模型输入、生成输出、保存和读取统一执行 `SimplifiedGuidePolicy`；下载的每次重定向也检查语言版本。不把繁体转简体后重新标记为简体来源。
- 提示词明确只使用简体中文资料和输出；无合格简体景点资料则停止并显示明确错误。
- 离线字形集合由固定版本 OpenCC 数据派生，共 3197 个繁体专用字符；共用字“乾隆”“著名”等仍允许。许可证、来源及哈希保留在 `third_party/opencc/`，许可证和字形文件已打包入 APK。
- 旧繁体缓存停止展示，原文件保留。旧 attempt 标记允许一次按简体规则重新整理，新标记先于网络请求写入；失败后重启不会重复自动消费。
