# v0.9.0 · 豆包搜索，民间攻略

目的地介绍改用豆包搜索，优先从游记、美食体验和已有路线中寻找旅行信息，保留来源供你查看。

## 更新内容

- **替换为豆包网页与图片搜索**：DeepSeek 继续负责整理资料；景点、美食、一日游和两天一夜分别检索，资料不足时有限补查。
- **优先民间内容**：保留携程、马蜂窝，加入穷游、什么值得买、新浪和小红书等来源；政府、官媒不再作为主要攻略语料。
- **改善景点和美食补图**：支持景区安全简称和具体菜名匹配，只为缺图条目补充，保留可用旧图；美食照片标明菜品参考图。
- **路线有原文可查**：核验景点、游览先后与跨日顺序，玩法中可以打开攻略原文。不满足证据要求的路线不收录。
- **景点、美食各最多 10 项**：单次整理和累计保存均遵循此限制；每项最多 3 张照片，每城市仍有 100 张保护上限。旧缓存按新上限读取，手动更新时保存。
- **更稳妥地处理限流**：识别搜索服务的业务限流，按间隔串行请求并有限重试。

整理和补图由手动操作触发，打开城市不会自动消耗内容服务额度。搜索结果随网络内容变化；没有合适图片或路线时保留文字，不保证每城凑满 10 项。民间来源也可能转载或使用 AI 整理，请结合原文判断。

## 下载与升级

下载附件 `train-trip-v0.9.0-release.apk`，支持 Android 8.0 及以上，版本号 `0.9.0` / versionCode `14`。沿用公开正式版生产签名，可直接覆盖同签名旧版并保留本机数据，另附 `.sha256` 校验文件。

**升级后请在设置中单独填写豆包搜索 Custom 版 API Key；旧 Tavily Key 不会自动迁移。** DeepSeek 配置继续保留。APK 不包含个人 Key，查票、想去清单和内置介绍无需配置内容服务。

历史设备专用包与公开正式包签名不同，无法交叉覆盖。遇到签名冲突时，请保留原安装与数据，使用同签名升级包。

已通过核心测试、正式构建与签名检查；详细覆盖升级结果见[发布验证](https://github.com/chengweiv5/train-trip/blob/main/docs/verification/2026-09-23-v0.9.0-release.md)。目的地分页滚动位置有一项在旧代码上同样出现的自动化断言失败，详见[功能验收](https://github.com/chengweiv5/train-trip/blob/main/docs/verification/2026-09-23-community-search.md)。
