# 目的地灵感设计

2026-09-19：用户已确认“城市亮点卡片 + 目的地玩法详情”，优先帮助判断景点、美食和玩法是否值得去。

## 范围与体验

首版覆盖天津、济南、青岛、大同、洛阳 5 城；用户在执行中明确缩小为 5 城。结果卡片保留原有车次、日期、席别、到达站与查询时间；增加实景图片、两三个标签、一句话推荐理由及建议天数。主卡片打开目的地详情，同时提供“查看车次”直达入口。

目的地详情展示照片、推荐理由、建议天数与步行强度、3 个代表景点或体验（吸引力、建议耗时、是否远郊）、3 种地方美食、1 日/2 日玩法切换、季节和出行提醒。底部固定“查看有票车次”，进入原有选座、核验及 12306 流程。从目的地进入车次时，返回车次页回到对应目的地，返回目的地回到结果并保留列表位置。直接从结果查看车次时返回结果。未覆盖的城市仍可正常查看车次；详情明确说明暂无资料。数量待核验结果保留原标记。

建议游玩天数为编辑建议，1 日/2 日是参考玩法，不推断用户旅行长度；出发日范围仍仅表示可选出发日。当前不加入全局旅行天数筛选、城市对比、酒店价格、天气、返程查询、个性评分或完整自动行程。

## 内容与来源

城市资料与压缩图片打包在 APK 中，离线可读，不额外等待网络。景点、美食根据本次实际读取的旅行资料整理，来源 URL 与核对日期在详情可见并可打开。停留时长、强度和路线组合为编辑建议；不声称来源验证了精确耗时。门票、营业时间和预约规则不写未经核实的数值或实时结论，提醒以景区官方信息为准。季节提示为一般气候经验，不当作出行日期的天气预报。

使用有明确许可和作者署名的 Wikimedia Commons 实景图，保留原作品页、作者、许可链接及缩放/裁剪说明。不得以城市名称推断一个来源图片适用于另一个城市。缺图显示中性底色，不阻断车票功能。正文采用原创提炼，参考 Wikivoyage 时提供来源与 CC BY-SA 4.0 链接，并说明整理改写，改编正文按 CC BY-SA 4.0 提供；图片单独遵循各自许可。

## 模块与接口

- core DestinationGuide.kt：GuideSource、DestinationPhoto、DestinationExperience、Food、DayPlan、DestinationGuide 与 DestinationGuides。按已有 cityId 精确查找，资料缺失返回 null。资源 JSON 在首次访问时加载为不可变映射；解析失败降级为空，不影响余票逻辑。
- core resources/destination_guides.json：5 城资料及来源、照片许可；与 StationCatalog 的城市标识关联，测试验证首版 5 城覆盖，其他默认目的地返回 null。
- app DestinationGuideScreen.kt：目的地详情、离线照片显示和来源链接。图片按 photo.assetName 从 assets/destinations 加载并通过 remember 缓存，失败使用底色。
- ResultsScreen.kt：卡片摘要和独立查看车次入口。
- AppViewModel / TrainTripApp：加入 DESTINATION 页面与详情来源路径，系统返回与屏内返回一致。结果/目的地/车次三个页面各保留滚动状态，目的地和车次状态按 cityId 隔离。
- 现有 design/train-trip-v1.pen：在当前隔离工作树中同步可编辑卡片和目的地详情样例，不修改主仓库正在打开的设计。

## 验收

核心测试覆盖 5 城资料匹配、未知城市、字段与许可完整、路线景点引用有效、所有图片存在。Android 离线样例测试覆盖结果→目的地→车次→返回、直接查看车次、1/2 日切换、无资料城市、来源入口和大字体。APK 构建、lint 与现有相关交互回归必须通过；不以模拟数据冒充实时余票验证。

Pencil 与运行界面进行结构、布局、OCR 和视觉检查；同时确认图片并非占位及署名可读。交付可安装 APK 与验证记录。连接的个人手机不用于清空设置或测试重置；本轮默认交付安装包，设备覆盖安装须符合用户已有授权范围。
