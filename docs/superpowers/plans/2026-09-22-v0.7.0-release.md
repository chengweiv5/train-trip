# v0.7.0 发布计划

> **For agentic workers:** 在当前会话按步骤执行；本机未安装 superpowers 执行子技能。用户已授权提交、推送并发布，无需再次确认。

**Goal:** 发布包含当前已确认功能的 v0.7.0，提供正式签名 APK 和校验附件。

**Architecture:** 保持现有功能与数据格式，版本升至 0.7.0 / 12。沿用公开版生产签名，在独立模拟器验证 v0.6.0 覆盖升级；先验证完整草稿附件，再公开 Release。

**Tech Stack:** Gradle、JDK 21、Android SDK 36、apksigner、ADB、GitHub CLI。

## 约束

- 功能分支 `codex/release-v0.7.0`；刷新远端并确认快进后使用 `git push origin HEAD:main`，不强推。
- 不将服务 Key、签名私钥、个人配置或设备专用签名包上传 GitHub。
- 不操作个人手机或其他任务的模拟器。现有设计稿随功能提交推送，历史版本画板保持原标签。
- 不新增行为；不因版本号变更重复全部界面测试。沿用已通过的 28 项相关回归，验证新包构建、签名和正式版升级。
