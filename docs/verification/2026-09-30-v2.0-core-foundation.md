## 已实现的公开接口

`core/src/main/kotlin/cn/traintrip/core/waitlist/WaitlistFlow.kt`：纯状态机，公开 start / accept；需求键包含日期、车次、起终站和席别，乘客身份及票种与账号绑定；组合能力上限由调用方提供，无猜测默认上限。

- 一次授权，每轮提交全部剩余需求；仅精确归因拒绝项自动排除，订单创建/耗尽即停止。
- 无法归因、集合外拒绝、其他业务拒绝暂停，不猜测删项。
- 超时/未知返回查原请求；临时未发现订单不等于确定未创建。
- 只有适配器能提供明确的、请求级未创建证据时才进入可继续态，仍需用户继续动作。
- 停止和退后台不撤销在途请求，不忽略迟到成功；截止时间过期停止续提。
- 账号/乘客集合/票种变更禁止继续旧请求；过时 attempt ID 和终态事件不重启自动流程。

`WaitlistCoordinator.kt`：公开 Gateway / Store 接口及 start / stop / recover / continueRemaining / checkOrder。

- 每次先保存状态再调用 Gateway；保存失败没有后续网络发送，当前实例禁止使用旧内存继续。
- 状态互斥与网络互斥分离，提交等待期间可及时停止；网络异常保守进入未知结果核对，不自动重试。
- 进程恢复只核对 pending 请求，不重放提交；取消任务后持久记录仍保留未决请求。
- 避免重复点击开启两个并发任务；暂停/恢复不能覆盖无法归因等必须人工处理的原因。
- 凭证不属于状态模型，只接收应用本地引用；Gateway 必须校验真实会话绑定、归因证据、返回数据及错误脱敏。当前无生产 Gateway / Android Store 实现，测试使用内存 Store 和脚本 Gateway。
