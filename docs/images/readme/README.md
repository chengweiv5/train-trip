## 版本与采集

- 10 张流程截图、四套主题选择页与首页对比图均于 2026-09-23 重新采集，来自 **v1.0.0 / versionCode 15** 的实际 Android Compose 界面。
- 采集基线为 `4430a49`；应用源码与公开 `v1.0.0` 标签 `2d16990` 一致。使用本地 Debug 构建运行临时离线采集程序，运行时读取并断言版本为 `1.0.0 / 15`，没有改动生产界面。
- 使用独立 Android API 36 模拟器 `train_trip_v10_theme`，1080 × 2400、标准字号。结果页使用 320 dpi，其余页面使用 360 dpi，以完整展示主要内容和操作。未操作个人手机或其他任务的模拟器。
- 流程截图只等比例缩小并压缩为 JPEG，尺寸为 576 × 1280；没有改写图片中的文字或替换界面元素。主题对比图将四张完整截图等比例缩小后横向排列，不拼接不同页面的局部内容。
- 日期、车次、余票、收藏与离线缓存使用演示数据，不是实时可购车票或用户个人数据。首页选择 5 座城市；结果页独立演示天津、济南两城的查询完成状态。
- 天津景点、美食和玩法使用应用内置资料；没有现场调用搜索或模型生成内容。离线管理中的天津条目是内置文字另存的采集样本，空间数值由实际缓存文件计算。
- 设置页展示未配置服务状态和「主题配色」入口；采集过程未输入或展示个人 Key。四套主题截图均来自同一 v1.0.0 构建。
