## 实现结果

- 底部查票 / 想去双栏目，子页面隐藏底栏；返回保留实际入口。收藏保存城市身份、名称、省份与时间，本机原子存储；批量添加、跨入口星标同步、取消、撤销和失败重试。
- 单城查票沿用首页当前有效条件，固定目的地，独立草稿；只有点击查询才联网，不修改首页筛选。重新添加创建新草稿，介绍同次查询保留页签和阅读位置。
- 设置中可管理已下载介绍及图片。删除显示实际占用、确认、取消和部分失败；收藏与服务密钥保留。支持旧图归属记录、原子文件备份恢复及残留重试清理；删除后回退内置介绍或空态。
- 新城市统一手动整理，不自动调用模型或搜索。新正文原子提交后立即显示，图片使用独立版本文件；图片失败或取消仍保留新正文并显示部分成功。正文提交前失败保留旧内容；删除等待在途任务取消，过期回调不重新写回。
- 关于与更新从安装包读取版本，手动检查固定 GitHub 仓库。完整分页、过滤草稿与预发布、语义版本比较；仅完整 APK 和 `.sha256` 附件显示下载入口。未检查、检查中、新版、最新、失败分别呈现，离开取消，失败不冒充最新。
