# Train Trip Android V1 Implementation Plan

> For agentic workers: execute the approved scope task by task in this session. The referenced superpowers execution skills are not installed; continue with the available build, test and review tools.

**Goal:** Deliver an installable Android APK that finds destinations using real outbound ticket queries, with explicit query coverage and 12306 handoff.

**Architecture:** A pure Kotlin core owns station parsing, inventory semantics, query planning and cancellable search. The Compose app owns editable filters, saved preferences and screens; it consumes immutable progress/results. A normal anonymous HTTPS session isolates the private 12306 response format from UI.

**Tech Stack:** Kotlin 2.2.10, Gradle 8.13, AGP 8.13.2, Compose Material 3, coroutines, OkHttp, Gson, JUnit.

## Global constraints

- minSdk 26; compileSdk/targetSdk 36; JDK 21; no Google Play Services.
- Default Beijing, 1 adult, all seats including standing, unlimited duration, outbound/direct only.
- Preserve source timestamp, raw seat status, city identifiers, passenger boarding date and overnight duration.
- No login, booking, payment, background monitoring or automated retry loop.
- Current nationwide completeness is unverified. Show the named experimental destination scope before and after search; never imply nationwide completion.
- Protect existing design and documents. Use codex/android-v1; no remote is configured.
