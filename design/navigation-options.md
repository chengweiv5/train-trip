A 的底栏只用于查票首页与想去清单这两个根页面；查询结果、城市详情与设置作为后续页面进入，返回保留根页面位置。B 沿用首页为主要入口的结构，新增入口会使查询表单向下移动一行。

## 共用设置

设置中保留模型和搜索服务，新增离线内容、关于与更新。离线内容按城市列出下载空间和更新时间，提供阅读、更新及删除入口；更新失败保留旧内容，删除下载资料保留收藏和密钥。内置资料随应用提供，不计入可清理空间。

关于与更新展示当前版本、检查更新、更新说明和 GitHub 项目；发现更新后去发布页下载，由系统确认安装。版本状态、容量和日期均为设计示例。

正式发布的后续设计约束：延续生产签名、递增 versionCode、验证 Release 和调试关闭、排除密钥、校验 APK 后上传并重新下载核对。没有新增服务端维护需求。
