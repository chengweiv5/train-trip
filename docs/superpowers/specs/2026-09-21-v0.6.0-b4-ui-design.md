## 顶部

首页：32dp 湖蓝圆角火车标识，18sp 应用名“有票就出发”；右侧设置视觉尺寸36dp，点击区域至少48dp。主标题“先看有票，再选目的地”22sp/约29sp行高，辅助说明13sp。渐变从系统状态栏连续延伸到品牌区底部白色。标题/导航至少56dp，引导区至少68dp；正常字号第一张卡片位于状态栏后124dp。主内容可滚动，设置入口始终可见。

想去：同样32dp星标容器、22sp标题，添加城市使用36dp圆角浅色按钮、至少48dp点击区域；概况位于标题下方约40dp区域。无收藏/加载/读取失败仍显示相应状态，概况不能把读取失败误报成零收藏。列表保留原状态恢复与滚动行为。

宽度320dp、1.3倍字体下允许标题/说明自然换行，顶部高度随内容增长，不剪裁，不与右侧操作重叠。其他页面用现有返回式顶部，不额外增加品牌标识。
