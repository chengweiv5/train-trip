# 国内目的地图文替换设计

2026-09-19。用户确认正文和照片都改为国内来源，并明确个人自用、非商业使用，不以逐张申请授权为前置步骤。沿用已提出的开发时整理、APK 离线展示方案。

## 范围

仅更新天津、济南、青岛、大同、洛阳五城。景点、美食依据实际读到的国内政府、文旅及景区资料重新提炼，保留原文链接和核对日期；一日、两日路线、耗时和强度属于编辑建议。未覆盖城市继续正常查询车次。保留最新主线的四分页、返回与滚动状态，不新增云服务、运行时采集、平台登录或自动更新。

照片从国内公开原文中选择可识别的真实城市景观，个人版压缩打包离线展示。记录来源网页、实际署名或“原页面未署名”、缩放说明及本地原图摘要。不会把网站发布者臆写成摄影师，也不沿用旧照片的 CC 许可。失效页面换用可读来源；不绕过验证码、登录、付费或证书验证。

## 模型与界面

GuideSource 保留 title、url、checkedOn。来源 URL 允许有效 HTTP 或 HTTPS 链接，因为少数官方旧站只提供 HTTP；这些链接通过外部浏览器打开，App 不下载网页。

DestinationPhoto 保留 assetName、description、sourceUrl，使用 credit 记录完整署名；license 与 licenseUrl 改为可选且必须成对有效。图片未知授权时不显示许可按钮。来源弹窗保留正文来源、核对日期、图片出处，移除固定“改编正文：CC BY-SA 4.0”，说明国内资料整理、玩法为建议和图片仅用于个人离线浏览。每个分页的入口和弹窗滚动保持不变。
