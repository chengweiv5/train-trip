# v2.0 候补主页导航修复

日期：2026-10-01，Asia/Shanghai。

## 用户确认的方案与改动

用户指出“候补”与“候补车次”都显示返回按钮，无法辨认主页；随后确认以下局部调整：

- “候补”是唯一主页，左上角始终不显示返回按钮。
- “候补车次”保留顶部返回；顶部返回和系统返回均回到候补主页。
- 主页已有查询时显示“查看上次结果”，不再借用返回箭头进入旧结果。
- 返回及查看旧结果不清除已选车次、查询结果和条件草稿；旧结果使用原已应用条件，不混入未应用草稿，也不重新查询。

实现移除了主页根据 `applied` 动态显示返回的判断，将 `WaitlistViewModel.back()` 的主页分支改为留在主页；新增仅在主页、有已应用查询且非订单操作中可用的 `showLastResults()`。

没有改动其他子页的返回层级、底部模式切换、登录或生产下单接口。未修改 Pencil 文件。
