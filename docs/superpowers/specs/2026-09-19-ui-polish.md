# 日期与查询界面修复

用户授权修复三个问题，并要求所有界面变更同步到 `design/train-trip-v1.pen`。保持现有配色、查询行为和其他筛选项。

1. 日期：在一个底部日历窗口切换单日/日期范围；范围模式直接点选开始和结束，连续高亮。未选完整时不能完成；取消不应用，完成后保存。仍禁止过去日期并限制最多 31 天，未开售日期保持可选并由票源明确反馈。日历可跨月滚动。
2. 进度：6dp 连续轨道，左侧绿色按已处理查询项/总项推进；无分段间隙、无末端圆点。初始化显示空轨道和连接状态文字；有查询计划后显示确定进度，保持现有取消/继续逻辑。
3. 车次：中间使用真正的 1dp 分隔线，耗时与到达日期居中。耗时压缩为“1小时30分”格式，未知到达日不显示“当日”。常规宽度保留三列；窄屏/大字体时让耗时和到达日期置于两端时刻下方，完整可读。长站名可换行。

替代方案：继续系统双弹窗不能解决效率问题；自绘完整日历增加维护成本。因此使用 Compose Material 日期组件。进度组件通过显式样式配置修正；行程信息抽成小组件用于布局验证。

验收：构建和 lint；离线 UI 测试选择跨月范围、取消/保存、未完整选择状态；0/50/100% 进度截图与像素检查；长耗时和跨日车次在正常/放大字体下布局检查。Pencil 更新现有日期、进度、车次组件和交接说明，回读、渲染、OCR、裁切与可编辑性检查。测试仅操作临时模拟器，保留真机数据。
