# v1.0 四套主题实施验收

2026-09-23，基线 `ef0b1e6`，功能分支 `codex/v1.0-theme-design`。用户确认[设计稿](../superpowers/specs/2026-09-23-v1.0-theme-design.md)后完成 Android 实现及本地验证。

## 实现结果

- 设置 → 外观 → 主题配色，可选择晴空蓝、松林绿、暖阳橙、暮山紫，默认晴空蓝。点选立即预览，保存成功提示；重复选择不写入。
- 应用根节点统一提供十个颜色角色及 Material 3 色板。首页、导航、卡片、选择、标记、设置和弹层沿用同一来源；白底固定，有票绿固定为 `#0F7952`。原生时间滚轮在 Compose 更新时应用主题色。
- 主题单独保存在私有 `theme-choice` 文件，使用 AtomicFile、同步落盘及原始 ID 回读验证。保存失败恢复最近成功选择；读取异常保留原文件并提供重试。快速选择不会被旧结果覆盖。
- 主题页使用带名称和状态的单选卡片；宽度小于 360dp 或字体缩放超过 1.15 时改为单列。预览按钮无点击行为，成功提示遵循无障碍建议时长。
- 切换不重建业务 ViewModel、不改变业务导航 key、不引入搜索或模型调用。筛选、车次标记与现有页面状态独立保存。敏感服务配置页继续设置 FLAG_SECURE，主题页可正常截屏。

## 交付边界与回滚

本轮为 v1.0 功能候选，保持现有版本标识 `0.9.0 / 14`。构建产物为 `app/build/outputs/apk/debug/app-debug.apk` 和 `app/build/outputs/apk/release/app-release-unsigned.apk`。未推送、未发布、未操作个人手机，未执行生产签名覆盖升级或真实搜索/模型服务验收。

源码与文档可反向提交，修改前备份在 `.verification-private/v1.0-themes/backup/`。旧代码忽略独立主题文件即可；回滚不需要卸载应用、清空收藏、设置或离线内容。
