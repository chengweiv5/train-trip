# Tavily 目的地资料检索设计

用户已选择搜索 API + DeepSeek + 本机缓存方案，并指定以 Tavily 替代博查。不维护服务端，保留个人自用本地交付范围。

## 数据流与边界

新城市在两项密钥齐全且未尝试时，手机向 Tavily 官方 HTTPS Search 接口顺序发送景点、美食两条含省市名的查询，每条 basic、最多 6 条结果、禁用 auto_parameters 与 AI answer。明确限制国内文旅政府、携程、马蜂窝及国内媒体域名；程序再校验域名边界、去重和城市名，最多保留 10 篇，每篇正文最多 2400 字。Tavily 是检索服务，内容来源仍显示原始国内网站。

`TavilyGuideSource` 实现已有 `GuideMaterialSource`，通过私有 key supplier 按请求读取 Tavily 密钥；不缓存密钥到资料对象。`GuideMaterial` 新增带 id/title/url/content/kind 的 `documents`，原 places/foods 默认兼容现有携程路径与测试。资料不完整或无景点查询结果时停止，不调用模型。第二条搜索的网络、鉴权、额度错误同样显式失败，不静默吞掉；正常零美食允许继续。

`DeepSeekGuideGenerator` 针对 documents 使用独立的提取协议，一次调用完成筛选：每项必须提供合法 sourceId、name 和逐字 quote。name 必须出现在对应 quote（模型漏掉紧邻段落的【标题】时，程序只可补入该原文标题），quote 必须属于该文档正文；景点必须出自景点查询文档，美食必须出自美食查询文档。逐条校验，不匹配的条目丢弃；没有任何有效景点时拒收整份。正文展示经过校验的短引文，不允许模型增写票价、开放时间或口味。位置缺少可验证的 location 引文时使用“城市名 · 具体位置请查地图”。简介标签可由模型概括；禁止实时数据及无依据训练记忆。路线可以为空；不完整的可选路线单独丢弃，仅允许已选景点引用，时长、路线明确作为建议。使用原来已验证的模型 id `deepseek-flash`。

每个条目保存原文 URL 和引用，来源表仅包含实际使用的文档，日期为检索日。模型不能提供新 URL 或图片。城市名过滤与原文匹配不是事实真伪的自动证明；检索摘要可能过时，页面继续提示核对原文和最新公告。

## 图片

只考虑 Tavily 结果项内自带的图片，不采用无法定位原文的顶层图片列表。图片必须 HTTPS、属于批准的国内来源域名或携程图片 CDN，标题/原文/图片说明可对应所选景点，图片说明长度 5–300 字且包含景点名；拒绝 logo/footer/banner/icon/qrcode/beian 等资源名。保留原文网页链接，署名写明页面刊载、未提供摄影者。缺少这种证据或下载/解码失败时不展示照片。下载限制 5 MiB，校验每次重定向，解码限制及本机缩图沿用原实现。

## 配置与缓存

`DeepSeekSettings` 保留原 preference、encryptedKey 和 Keystore alias，新增独立 `TavilySettings` 使用另一 preference 与 alias。同一设置弹窗分列两项状态、遮罩输入、独立移除。空输入保留原值，先验证两项输入后再保存，任何成功/失败后回读两项状态，允许错误时用户重试。更换/移除任意密钥先取消活动请求；移除一项不得影响另一项或已有缓存。密钥不写仓库、APK、日志或网络 URL，仅在对应官方 API 的 Authorization header 使用。

既有生成缓存、内置五城和失败 attempt marker 保留。缓存优先离线打开；任一密钥缺失时不发搜索/模型请求，不写 attempt。失败与退出不自动重试；用户明确重试后才重新计费。首次新城正常成功用两次 basic 搜索（预计 2 credits）和一次 DeepSeek；实际用量以提供方为准。界面说明两家服务的用途和调用费用。

## 验收与交付

测试真实 HTTP 请求参数、鉴权隔离、错误映射、重定向不跟随、来源域名与城市过滤、无景点停止；测试伪造 sourceId/name/quote 拒绝、美食空缺、可选照片和旧结构兼容。Android 测试两把密钥独立存取、既有 DeepSeek 配置保留、缺密钥不调用、失败不自动重试与缓存。

真实 API 小批量验证：已有泰安/苏州四次 basic 探测成功，共 4 credits。完成后使用真机明确重试泰安，检查成功页面、原文来源、本机文件与重启缓存不再次请求。只在独立模拟器做 instrumentation；真机覆盖安装保留数据，不卸载、不清数据。构建、单测、lint、密钥扫描、文档、备份与本地提交完成后通知；不把个人素材公开推送。回滚使用备份 APK 与功能分支提交，不删除缓存。
