# 0.1.1 界面修复验证

分支：`codex/ui-polish`。本次修复只涉及日期交互、查询进度和车次信息排版，对应更新 `design/train-trip-v1.pen`。

## 变更

- 日期不再依次打开两个系统弹窗。单日/日期范围均在同一个底部日历中选择；范围连续高亮、跨月滚动；未选完整不能完成，取消保留已应用值。
- 查询进度显式取消 Material 默认 gap 和 stop indicator，以 6dp 连续轨道表示已处理查询项比例；初始化显示空轨道与连接说明。
- 车次中间用真正的分隔线替代字符横线，紧凑显示耗时和当日/跨日说明。窄于 300dp 的内容区域或字体超过 1.15 倍时，将中间信息放到时刻下方。
- 版本 `0.1.1` / versionCode 2。保留 `0.1.0` 安装包。
