# UI 旧提示与重复文案清理

已巡检首页、结果页、目的地选择、出发地/席别/人数/日期/时段弹层、车次页、目的地介绍及来源弹层。

## 调整

- 移除结果页“查看本次 N 个城市范围 · 可能未覆盖全部目的地”入口及旧范围说明弹窗，移除首页“首版”说明。
- 移除行政区划快照、车站字典、原始余票字段解释等实现细节；保留不可选城市的具体原因、候补排除和多人同车同席规则。
- 移除车次页重复的选席提示、余票变化说明，以及无票页重复的修改条件按钮。
- 查询成功简化为“查询完成”；失败、未开售和待查询仅在非零时显示，继续查询、重试及具体原因保留。
- 日期摘要改为“共 N 天”；日期限制及实际错误仍显示。目的地资料缺失改为“暂无目的地介绍”，移除离线存储说明，保留来源、核对日期和版权署名。

不改变查询范围、筛选规则或数据解析。保留跨午夜说明、查询时间、部分失败后的旧数据提醒，以及在 12306 App 内填写条件并购票的说明。
