# v0.6.1 飞书反馈设计

用户已确认四项修改范围。以下实施细节沿用现有 B4 视觉和数据语义；无新增付费调用、自动抓取或服务器。

## 1. 想去按省组织

沿用当前收藏卡片，列表插入省份标题和城市数量。省份按现有行政目录顺序稳定排列；省内维持当前最近收藏优先。默认展开，不增加折叠操作；取消、撤销、点击介绍、单城查票与无站城市禁用保持原行为。省份取当前目录，旧收藏找不到城市时回退保存的省份，不丢记录。

## 2. 全页面顶部统一

复用首页和想去的冰蓝至白色渐变、湖蓝强调色、36dp圆角按钮和48dp点击范围。子页面保留返回语义，左侧返回按钮、左对齐标题，右侧为修改/收藏等既有操作；不增加多余装饰图标。系统状态栏颜色连续，长标题和大字体自动增高，不挤压返回或操作区域。弹窗及筛选底部面板继续原样，避免把页面顶部样式硬塞入弹窗。

## 3. 目的地多图

城市概览下方加入可横滑的实景相册，首图优先展示主要景点，最多5张。显示1/N、说明与来源；点击可查看大图，空相册不占空白。结果卡片继续使用首图。新介绍保留可靠来源中的多张图片，去重、过滤装饰/繁体资源；图片关联需要有城市/景点及来源证据，数量不足时少放，不凑图。旧单图缓存继续兼容；生成和更新仍由用户手动发起。正文先保存，图片分别下载，失败保留已成功部分并报告数量。离线管理包含全部相册文件。新正文提交时清空旧相册引用并清理不再被其它城市使用的旧图；新图每成功一张就原子保存新的相册引用。取消发生在正文提交前则保留旧介绍，提交后则保留新正文与已成功保存的图片，清理无引用的临时图。失败不回退旧图，以免新正文与旧图片不对应。Tavily 根级图片若无原文页面归属，必须同时含城市名和已采纳景点名且来自受信任国内图源；来源明确标为搜索图片并链接图片本身，不冒充原文配图。

## 4. 上次检查时间

持久保存上次已完成检查时间、成功时间与成功版本结果。再次进入或重启后显示上次记录，不能恢复成尚未检查；正在检查/失败与历史成功记录分开。首次从未检查仍显示尚未检查；取消请求不更新完成时间，失败显示本次失败时间并保留上次成功时间。历史结果不冒充本次已确认最新，主按钮仍可手动检查。只保存公开版本信息，不涉及服务Key。

## 验证重点

收藏跨省顺序/取消撤销/未知城市；全部页面普通字号和320dp/1.3倍字体顶部可达；旧单图缓存兼容/多图部分失败/取消/删除；检查成功与失败的页面往返和进程重启恢复。版本0.6.1 / versionCode11。源码与Pencil同步后构建签名Release，是否安装/发布遵循后续交付指令。
