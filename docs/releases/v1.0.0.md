# v1.0.0 · 四色主题，随心出发

新增四套浅色主题，按自己的喜好换一种颜色；同时完善目的地的多日玩法，让参考行程更完整。

## 更新内容

- **四套主题可切换**：晴空蓝、松林绿、暖阳橙、暮山紫。进入「设置 → 外观 → 主题配色」，点选立即生效，下次打开仍会保留；默认晴空蓝延续原有外观。
- **全局配色保持一致**：页头、按钮、卡片、导航和选中状态同步切换；有票、提醒等状态色保持一致，切换保留筛选、车次标记和想去清单。
- **照顾小屏和大字**：主题选项可自动改为单列，页面可滚动；保存失败会恢复先前主题并提示重试。离线也可切换。
- **支持独立的多日玩法**：支持 1 天、2 天及更多天数，每城市最多保留三种天数，每种一条。玩法地点可独立于景点列表；同一条多日玩法取自同一篇攻略，并保留来源链接。
- **改善玩法遗漏**：资料足够时补充缺失的路线，支持识别三日等多日正文；景点、美食或玩法某类缺失，不再阻止其他可用内容保存。旧景点、照片和收藏继续保留。

玩法可用天数取决于检索资料，不保证每城凑齐三种。手动整理或更新目的地才会调用内容服务，升级不会自动重新生成已有介绍。

## 下载与升级

下载附件 `train-trip-v1.0.0-release.apk`，Android 8.0 及以上可用，版本 `1.0.0` / versionCode `15`。沿用公开正式版的生产签名，可覆盖同签名旧版并保留本机数据，另附 SHA256 校验文件。

已安装历史设备专用包的用户需要同证书升级包；签名冲突时保留原安装与数据。APK 不包含个人服务 Key；查票、想去清单、内置介绍和主题切换无需配置内容服务。

验证包括 146 项核心测试、6 项主题状态测试及此前通过的 24 个 Android 用例，另行核验正式包签名和 v0.9.0 覆盖升级。详情见[发布验证](https://github.com/chengweiv5/train-trip/blob/main/docs/verification/2026-09-23-v1.0.0-release.md)与[主题验收](https://github.com/chengweiv5/train-trip/blob/main/docs/verification/2026-09-23-v1.0-themes.md)。
