# v0.8.0 · 图随景点，刷新保留积累

景点和美食现在各有自己的相册；更新介绍时，已保存的内容会继续保留。

## 更新内容

- **图片对应具体条目**：照片放在对应景点或美食下方，支持横滑、查看大图与来源；每个条目最多 3 张，每座城市最多 100 张。
- **全量更新自动补图**：保留可用旧图，只为没有图片的条目寻找照片；已有 1–3 张图片的条目不会重复补充。
- **刷新保留旧景点和美食**：本次搜索遗漏的旧条目继续保留，同项更新介绍，新增内容追加；累计条目可以超过原来的 5 个景点和 6 种美食。
- **修复内容和图片关联**：处理景点编号变化及明确别名，避免刷新后玩法或照片对应到其他条目。
- **离线保存更稳妥**：图片下载失败或取消时保留已保存内容；累计介绍变大后仍能重新打开，超出存储保护限额时保留原缓存。

已经被旧版本覆盖的历史条目不会凭空恢复；没有找到合适图片时，条目仍以文字展示。以上补图与更新由手动「全量更新」触发，打开城市不会自动调用内容服务。

## 下载与升级

下载附件 `train-trip-v0.8.0-release.apk`，支持 Android 8.0 及以上。版本号为 `0.8.0`，versionCode 为 `13`，沿用此前公开正式版签名，可直接覆盖升级并保留本机数据。另附 `.sha256` 文件用于完整性校验。

APK 不包含个人 DeepSeek 或 Tavily Key。查票、想去清单和内置介绍无需 Key；手动整理或更新其他城市时，使用你在设置中配置的服务。

历史设备专用测试包与公开正式包签名不同，无法交叉覆盖。遇到签名冲突时，请保留原安装与数据，使用相同签名的升级包。

应用用于发现目的地和查询直达去程余票，不提供抢票或代购。余票以 12306 实时查询及下单结果为准。
